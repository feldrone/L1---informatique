## 1. Core CS vocabulary
hardware: CPU, RAM, motherboard, storage device, peripheral — software: operating system (OS), application,
compiler, interpreter — network: server, client, bandwidth, latency, protocol — data: database, table, field,
query — development: source code, bug, to debug, repository, branch, commit, pull request — security:
password, encryption, firewall, vulnerability, phishing, malware.

## 2. Grammar for technical English
- **Present simple** for definitions/facts: "An OS manages hardware resources."
- **Passive voice** for documentation and lab reports: "The data is stored in a database." / "Errors were logged."
- **Imperative** for instructions: "Enter your password", "Do not close the window."
- **Zero/first conditionals**: "If the battery dies, the session stops." / "If you press Enter, the file will be saved."
- **Modals**: must (obligation), should (recommendation), can (ability), may (possibility).
- **Relative clauses**: "A compiler is a program that translates source code."
- Gerund after preposition/verb: "avoid creating duplicates", "keep the system running."

## 3. Documentation & reading skills
- Skim title/headings → locate figures & captions → read abstract/conclusion first.
- Contrast markers: however, whereas, nevertheless ; result markers: therefore, thus, hence ; addition: moreover.
- Units: 10 KB (kilobytes) ≠ 10 kb (kilobits) ; decimal point 3.14 (not comma).

## 4. Writing — useful templates
- Definition paragraph: what it is → what it does → how it works → why it matters.
- Short email/request: greeting, context, request (Could you please … ?), closing. Formal register: no contractions
  (do not, cannot), full sentences, polite modals.

## 5. Common mistakes (for francophone learners)
- its (possessive) vs it's (= it is) ; than (comparison) vs then (time) ; some vs any (negations/questions).
- Uncountables: information, advice, software, hardware — no *informations*, use "some information".
- False friends: actually = en fait (not actuellement = currently) ; library = bibliothèque (not librairie) ;
  to realize = se rendre compte (not réaliser = to carry out).
- Prepositions: depend ON, listen TO, good AT, different FROM, interested IN.
- Double negation is non-standard: "I don't know any of them" (not "don't know none").
- Subject required in English: "It is important" (not "Is important").
