# sources/ — registre et pièces justificatives

- `SOURCES.md` : registre principal (un enregistrement `# Source` par source officielle importante).
- Les PDF/captures utiles cités dans le registre peuvent être copiés ici **sans renommage**, dans un
  sous-dossier `archive-AAAA-AAAA/`, si les conditions de diffusion le permettent ; sinon, ne conserver que
  l'URL + date de consultation.
- Toute source non officielle (forum, blog, chaîne vidéo) n'a pas sa place dans ce registre ; elle ne peut
  servir que de **pointeur étiqueté SUPPLEMENTAIRE** dans un module, jamais comme preuve d'un fait officiel.
