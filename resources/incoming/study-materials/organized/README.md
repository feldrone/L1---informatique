# organized/ — zone de sortie classée (copies, jamais les originaux)
Chaque fichier déposé dans `../raw/` est analysé puis **copié** (l'original reste intact dans `raw/`)
vers `S1/<module>/` ou `S2/<module>/` **seulement si le contenu du document le prouve**.
Sinon → `UNCLASSIFIED/` avec la raison dans l'inventaire.
Règles : la classification se base sur le CONTENU (titre du cours, en-têtes, année, établissement),
pas sur la ressemblance du nom de fichier. Confiance < haute ⇒ UNCLASSIFIED.
Les répertoires S1/, S2/ de ce dossier ne sont PAS le curriculum : l'intégration dans les vrais
dossiers `S1/`/`S2/` du dépôt exige une autorisation séparée.
