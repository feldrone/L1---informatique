## TOPICS (présents dans le document)
- Intro : algèbre de Boole (1847, George Boole 1815-1864) ; variables binaires Vrai(1)/Faux(0) ; définitions état/variable/fonction ; exemples de phénomènes à 2 états (marche/arrêt, ouvert/fermé…)
- 1.1 Logique combinatoire : système en boucle ouverte, sorties = f(entrées) uniquement ; table de vérité
- 1.2 Propriétés de l'algèbre de Boole : somme de produits (SP) / produit de sommes (PS) ; commutativité, distributivité (a+bc=(a+b)(a+c)), absorptions (a+ab=a ; a(a+b)=a), complémentarité ; DUALITÉ (ET↔OU, 0↔1) ; LOIS DE DE MORGAN + généralisation à N variables
- 1.3 Circuits combinatoires : Si = F(E1..En)
- 1.4.1 Établissement de la table de vérité : colonnes = entrées+sorties ; lignes = 2^N
- Opérateurs fondamentaux NON/ET/OU (tables de vérité, représentations a̅, a·b, a+b) ; dérivés NAND (a/b), NOR (a↓B), XOR (a⊕b), XNOR — tables complètes ; NAND=ET+inverseur, NOR=OU+inverseur ; remarque : ET/OU/NAND/NOR multi-entrées possibles, XOR non
- TABLEAU RÉCAPITULATIF des opérateurs (notation, table, nom)
- LOGIGRAMME : traduction fonction→schéma de portes (exemple F = A·B̄ + B·C)
- FORMES CANONIQUES : 1re = somme de min-termes (disjonctive, la plus utilisée) ; 2e = produit de max-termes (conjonctive) ; les deux sont équivalentes (exemple de conversion donné)
