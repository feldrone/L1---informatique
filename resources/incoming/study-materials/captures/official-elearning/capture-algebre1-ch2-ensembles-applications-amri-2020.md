## Restitution structurée du contenu réellement lu
**Opérations sur les ensembles** : appartenance/inclusion/égalité ; ensembles P(E), ∅, complémentaire C_E ; différence A\B, différence symétrique A∆B=(A\B)∪(B\A)=(A∪B)\(A∩B) ; propriétés 1-10 (idempotence, commutativité, associativité, distributivité, De Morgan, C_E A ∩ A = ∅, C_E A ∪ A = E) ; exemples numériques sur E={1..8}.
**Produit cartésien** : A×B = {(x,y)} ; couple ordonné, (x,y)=(x₀,y₀) ⟺ x=x₀ et y=y₀ ; A×B ≠ B×A (exemple) ; ℝ² plan, ℝ³ espace ; ℚ ~ ℤ×ℤ*.
**Notions sur les applications** : fonction E→F (au plus une image) vs application (domaine = E tout entier) ; D_f ⊂ E ; identité I_A ; égalité de deux applications (même départ, même arrivée, mêmes valeurs) ; exemples f:ℝ→ℝ, x↦1/x (fonction) vs g:ℝ*→ℝ (application).
**Image directe / réciproque** : f(A)={f(x), x∈A} ⊂ f(E) ⊂ F ; f⁻¹(B)={x∈E : f(x)∈B} ⊂ E ; exemples résolus (f(x)=2x+1 sur [0,3]→[0,4], f([0,1])=[1,3]).
