## Restitution structurée du contenu réellement lu
**1.1 Introduction — sous-ensembles remarquables de ℝ** : construction historique ℕ (notation de Dedekind, 1888) → ℤ (équations x+3=2) → ℚ (Peano, 1895) ; décimaux D ⊂ ℚ ; irrationnels (√2, π, e ; développement décimal illimité non périodique) ; ℝ (Descartes 1637, notation de Cantor) ; chaîne d'inclusions ℕ ⊂ ℤ ⊂ D ⊂ ℚ ⊂ ℝ ; preuve d'irrationalité par l'absurde.
**1.2 Propriétés de ℝ** : (1)–(10) corps commutatif (addition/multiplication commutatives, associatives, éléments neutres 0 et 1, inverses, distributivité, annullement du produit) ; ordre total (réflexivité, antisymétrie, transitivité, totalité) → (ℝ, ≤) totalement ordonné.
**1.3 Archimède et partie entière** : propriété archimédienne (formes équivalentes) ; définition E(x)=[x] avec α ≤ x < α+1 ; graphe de la partie entière ; exemples E(2,852)=2, E(−3,5)=−4.
**1.4 Valeur absolue et distance** : définition par morceaux ; 8 propriétés (positivité, nullité, √(x²)=|x|, encadrement |y−x|≤δ ⟺ x−δ≤y≤x+δ, multiplicativité, inégalité triangulaire |x+y|≤|x|+|y|, version inversée ‖x|−|y|‖≤|x−y|) ; distance usuelle d(x,y)=|x−y| (symétrie, inégalité triangulaire, séparation).
**1.5 Intervalles** : définition (stabilité par ordre) ; segments [a,b], intervalles ouverts/semi-ouverts ; (suite du chapitre : voisinages, bornes, topologie — §1.6/1.7 lus : voisinage V de a ⟺ ∃ε>0, [a−ε,a+ε]⊂V ; max/min/majorants/minorants/ensembles bornés ; **théorème de la borne supérieure** (toute partie non vide majorée admet une borne sup ; caractérisation avec ε) ; exemples complets (A₁=]0,1], A₂={n∈ℕ:5≤n²≤25}, uₙ=(2n+1)/n : max=3∈A, inf=2∉A).
