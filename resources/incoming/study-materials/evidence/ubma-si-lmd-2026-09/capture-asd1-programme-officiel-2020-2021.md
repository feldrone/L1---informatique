## Contenu fidèle (restitution du texte obtenu ; quelques glyphes corrompus dans « Parties d'un algorithme » rendus tels que vus puis corrigés entre crochets)

> **Matière : Algorithmique et structure de données 1** — Crédits : 6 — Coefficient : 4 — Mode d'évaluation : Examen (60 %), contrôle continu « TD+TP » (40 %)
>
> **Chapitre 1 : Introduction** — bref historique sur l'informatique ; introduction à l'algorithmique.
>
> **Chapitre 2 : Algorithme séquentiel simple** — 1. notion de langage et langage algorithmique ; 2. parties [d'un algorithme] ; 3. les données : variables et constantes ; 4. types de données ; 5. opérations de base ; 6. instructions de base (affectations ; instructions d'entrée/sortie) ; 7. construction d'un algorithme simple ; 8. représentation d'un algorithme par organigramme ; 9. traduction en langage C.
>
> **Chapitre 3 : Les structures conditionnelles (en langage algorithmique et en C)** — introduction ; conditionnelle simple ; conditionnelle composée ; choix multiple ; branchement.
>
> **Chapitre 4 : Les boucles (en langage algorithmique et en C)** — introduction ; boucle Tant que ; boucle Répéter ; boucle Pour ; boucles imbriquées.
>
> **Chapitre 5 : Les tableaux et les chaînes de caractères** — introduction ; le type tableau ; tableaux multidimensionnels ; chaînes de caractères.
>
> **Chapitre 6 : Les types personnalisés** — introduction ; énumérations ; enregistrements (structures) ; autres possibilités de définition de type.
>
> **Références** : Cormen, *Algorithmes, notions de base* (Dunod, 2013) ; Cormen/Leiserson/Rivest, *Algorithmique*, 3ᵉ éd. (Dunod, 2010) ; Malgouyres/Zrour/Feschet, *Initiation à l'algorithmique et à la programmation en C* (Dunod, 2011) ; Berthet & Labatut, *Algorithmique & programmation en langage C* vol. 1-3 (2014, cel-01176120/21) ; Delannoy, *Apprendre à programmer en Turbo C* (Eyrolles, 1994).
