## Contenu fidèle (restitution du texte obtenu)

> **Matière : Structure machine 1** — Crédits : 5 — Coefficient : 3 — Mode d'évaluation : Examen (60 %), contrôle continu « TD » (40 %)
>
> **Chapitre 1** : Introduction générale.
>
> **Chapitre 2 : Les systèmes de numération** — définition ; systèmes décimal, binaire, octal, hexadécimal ; conversions ; opérations de base dans le système binaire (addition, soustraction, multiplication, division).
>
> **Chapitre 3 : La représentation de l'information** — codage binaire pur ; code binaire réfléchi (Gray) ; code DCB (décimal codé binaire) ; code excédentaire de trois (« excède de trois ») ; représentation des caractères (EBCDIC, ASCII, UTF) ; nombres entiers (non signés, signe et valeur absolue, complément à 1 « complément restreint », complément à 2 « complément vrai ») ; nombres fractionnaires (virgule fixe, virgule flottante norme IEEE 754).
>
> **Chapitre 4 : L'algèbre de Boole binaire** — définition et axiomes ; théorèmes et propriétés ; opérateurs de base (ET, OU, négation) et représentation schématique ; autres opérateurs (NAND, NOR, OU exclusif, implication) et représentation schématique ; tables de vérité ; expressions et fonctions logiques ; première et deuxième formes normales ; expressions avec circuits NAND/NOR exclusivement ; schéma logique d'une fonction ; simplification (méthode algébrique, **tableaux de Karnaugh**, **méthode de Quine-McCluskey**).
>
> **Références** : J. R. Gregg, *Ones and Zeros* (Wiley, 1998) ; B. H. Arnold, *Logic and Boolean Algebra* (Dover, 2011) ; A. Cazes & J. Delacroix, *Architecture des machines et des systèmes informatiques*, 3ᵉ éd. (Dunod, 2008).
