## Contenu fidèle (restitution du texte obtenu)

> **Matière : Analyse 1** — Crédits : 6 — Coefficient : 4 — Mode d'évaluation : Examen (60 %), contrôle continu « TD » (40 %)
>
> **Chapitre I : Le Corps des Réels** — ℝ corps commutatif ; corps totalement ordonné ; raisonnement par récurrence ; ℝ corps valué ; intervalles ; bornes supérieure et inférieure ; corps archimédien ; caractérisation des bornes ; fonction partie entière ; ensembles bornés ; prolongement de ℝ (droite numérique achevée) ; propriétés topologiques de ℝ ; parties ouvertes/fermées.
>
> **Chapitre II : Le Corps des Nombres Complexes** — opérations algébriques ; module ; représentation géométrique ; forme trigonométrique ; formules d'Euler ; forme exponentielle ; racines n-ièmes.
>
> **Chapitre III : Suites de Nombres Réels** — suites bornées ; convergentes ; propriétés ; opérations ; limites infinies ; infiniment petit/grand ; suites monotones ; suites extraites ; suite de Cauchy ; généralisation de la limite ; lim sup ; lim inf ; suites récurrentes.
>
> **Chapitre IV : Fonctions Réelles d'une Variable Réelle** — graphe ; paires/impaires ; périodiques ; bornées ; monotones ; max/min locaux ; limite d'une fonction ; théorèmes et opérations sur les limites ; continuité ; discontinuités 1re/2de espèce ; continuité uniforme ; théorèmes sur [a,b] ; réciproque continue ; ordre d'une variable — équivalence (Landau).
>
> **Chapitre V : Fonctions Dérivables** — dérivées à droite/gauche ; interprétation géométrique ; opérations ; différentielle/différentiabilité ; Fermat ; Rolle ; accroissements finis ; dérivées d'ordre supérieur ; **formule de Taylor** ; extremum local ; bornes sur un intervalle ; convexité ; point d'inflexion ; asymptotes ; construction du graphe.
>
> **Chapitre VI : Fonctions Élémentaires** — logarithme népérien ; exponentielle ; logarithme de base quelconque ; fonction puissance ; fonctions hyperboliques ; hyperboliques réciproques.
>
> **Références** : J.-M. Monier, Analyse PCSI-PTSI (Dunod, 2003) ; Bougrov & Nikolski, Cours de Mathématiques Supérieures (Mir, 1983) ; Piskounov, Calcul différentiel et intégral t.1 (Mir, 1980) ; K. Allab, Éléments d'Analyse (OPU, 1984) ; Calvo/Doyen/Calvo/Boschet, Cours d'analyse (Colin, 1976) ; Lelong-Ferrand & Arnaudiès, Cours de mathématiques t.2 (Dunod, 1978).
