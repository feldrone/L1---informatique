   marquée **« Non vérifié dans les sources officielles consultées »** dans les fiches de modules — ne pas
   les inventer, les relever directement dans le PDF ou auprès du département.
4. **Annuel 2026/2027** : la page Emplois du temps affiche l'année 2026/2027 — Semestre 1 (onglets sans
