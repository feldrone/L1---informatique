# resources/ — documents de référence du dépôt

- [`PROGRAMME.md`](PROGRAMME.md) : référentiel L1 SI (modules, UE, coefficients/crédits vérifiés, divergences
  ancien/nouveau programme documentées).
- [`sources/SOURCES.md`](sources/SOURCES.md) : registre des sources officielles consultées (institution,
  document, URL, date de consultation, ce que chaque source vérifie).

Rien ici n'est un support de cours : ce sont les métadonnées qui permettent à un étudiant de distinguer
l'information **officielle** du matériel **supplémentaire**.
