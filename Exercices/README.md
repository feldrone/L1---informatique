# Exercices — L1 SI (UBMA)

Arborescence centralisée des exercices, organisée **par semestre puis par module** :

```
Exercices/
├── S1/
│   ├── README.md
│   └── Algorithmique-1/      ← jeu pédagogique exemple (SUPPLEMENTAIRE — NON OFFICIEL)
└── S2/
    └── README.md
```

## Conventions

- **Un exercice n'est stocké ici que s'il ne vit pas déjà dans le module** (`S1/<Module>/TD/` etc.).
  Sinon, on met un lien relatif vers le fichier canonique — pas de doublons.
- Étiquettes obligatoires en tête de fichier :
  - `OFFICIEL — UBMA` : distribué par l'université (citer l'enseignant/la page d'origine, la date, le semestre) ;
  - `ENSEIGNANT` : fourni par un enseignant mais non publié officiellement en ligne ;
  - `SUPPLEMENTAIRE — NON OFFICIEL` : produit pour la révision (ce dépôt).
- Nommage : `AAAA-AAAA - module - theme - numero.md` (ex. `2025-2026 - ASD1 - boucles - 03.md`).

Référentiel des modules : [`../resources/PROGRAMME.md`](../resources/PROGRAMME.md).
