# L1 — Systèmes Informatiques · Université Badji Mokhtar — Annaba

Base de connaissances organisée pour la **1ʳᵉ année de Licence « Systèmes Informatiques » (SI)** —
**Faculté de Technologie · Département d'Informatique** — Université Badji Mokhtar — Annaba (UBMA),
régime **LMD** (Licence / Master / Doctorat).

> **Avertissement.** Ce dépôt est une **organisation pédagogique** de ressources pour la Licence
> 1 Systèmes Informatiques. Les informations académiques officielles (programmes, coefficients,
> crédits, évaluations, dates) doivent être vérifiées sur les publications courantes de l'université :
> https://factec.univ-annaba.dz/departements/informatique/ (Annonces, Emplois du temps, Planning des
> examens, Corrigés, Délibérations). Rien ici ne remplace un document officiel du département.

## Comment lire ce dépôt

- **Contenu officiel** : uniquement ce qui provient de `univ-annaba.dz` (université, faculté, département)
  ou du Ministère de l'Enseignement Supérieur. Chaque ressource doit citer sa source
  (registre : `resources/sources/SOURCES.md`).
- **Contenu supplémentaire** : tout support pédagogique produit dans ce dépôt est étiqueté
  **« SUPPLEMENTAIRE — NON OFFICIEL »** et ne doit jamais être présenté comme un cours de l'UBMA.
- **Statut des données** : un renseignement non trouvé dans les sources officielles est marqué
  **« Non vérifié dans les sources officielles consultées »** — jamais deviné.
- **Année universitaire** : les ressources sont datées (ex. `2025-2026`). La rentrée en cours est
  **2026/2027** ; le programme de référence documenté ici est celui de **2025/2026** (voir
  `resources/PROGRAMME.md` pour les divergences relevées entre sources officielles).

## Organisation de l'année

```
L1-SI-Annaba
├── S1/                  Semestre 1 — un dossier par module (01-… → 08-…)
│   └── <Module>/        README (fiche du module) + Cours/ TD/ TP/ …
├── S2/                  Semestre 2 — même convention
├── Exercices/           Exercices centralisés par semestre puis par module
├── Corrections/         Corrections (officielles / enseignants / pédagogiques non officielles)
├── Fiches/              Fiches de révision par module (supplémentaires)
├── Examens/             Archives d'examens par semestre, année et session (Normal / Rattrapage)
├── resources/
│   ├── PROGRAMME.md     Référentiel L1 SI vérifié (modules, UE, coefficients connus, divergences)
│   └── sources/         Registre des sources officielles consultées (SOURCES.md)
├── INDEX.md             Navigation complète — tous les modules
└── CONTRIBUTING.md      Règles : pas de fabrication, étiquetage, traçabilité
```
